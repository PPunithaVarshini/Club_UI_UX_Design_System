# 🎨 Club UI Design System

### A Reusable Design System for Consistent Digital Experiences

## 📌 About the Project

I created the **Club UI Design System** to establish a consistent visual language for student club websites and applications. The project focuses on reusable UI components, standardized design foundations, and responsive interface design to create cohesive and user-friendly digital experiences.

My goal was to simplify the design process by creating reusable elements and clear visual guidelines that can be applied across different projects.

## ✨ Key Features

- **Design Foundations:** Consistent colour palette, typography, spacing, and layout rules.
- **Reusable UI Components:** Buttons, input fields, dropdowns, checkboxes, cards, badges, and alerts.
- **Light and Dark Themes:** Alternative themes for different viewing preferences.
- **Responsive Design:** Interfaces designed to adapt to desktop and mobile screens.
- **Interactive Elements:** Form validation, feedback messages, and theme switching.
- **Accessibility Considerations:** Clear labels, visible focus states, and readable feedback.
- **Event Registration Prototype:** A practical application demonstrating the design system in action.

## 🎯 Project Objectives

- Create a consistent design language for digital interfaces.
- Improve UI consistency through reusable components.
- Reduce repetitive design work by establishing shared patterns.
- Design accessible and responsive user experiences.
- Develop a foundation that can be extended to future student club projects.

## 🛠️ Tools & Technologies

- **UI/UX Design:** Figma
- **Frontend Development:** HTML5, CSS3, JavaScript
- **Version Control:** Git and GitHub

## 🖥️ Project Preview

The project includes a responsive design-system showcase featuring design foundations, component examples, and a club event registration interface.

The registration prototype demonstrates form validation and interactive feedback. It is a demonstration and does not store or submit user information.

## 🚀 How to Run

1. Clone or download this repository.
2. Open the `prototype` folder.
3. Launch `index.html` in your web browser.
4. Explore the components, themes, and event registration interface.

No additional installation is required.
